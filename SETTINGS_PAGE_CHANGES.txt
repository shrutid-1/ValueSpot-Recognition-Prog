FLEX LAYOUT ISSUES:
  • Using flex items-start (top aligned) instead of flex items-center
  • Using gap-3 (12px) instead of gap-4 (16px)
  • Using space-y-5 (20px) wrapper instead of built-in row padding

INPUT SIZING:
  • No explicit width on inputs (defaulting to auto/100%)
  • Inputs appearing too narrow or stretched

STRUCTURE:
  • CardContent padding interfered with row structure
  • No border dividers between rows
  • Labels and descriptions in separate flex items created alignment issues
